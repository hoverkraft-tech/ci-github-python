# Agent instructions

Follow the shared [Hoverkraft engineering guidance](https://github.com/hoverkraft-tech/.github/blob/main/AGENTS.md).

This repository provides opinionated Python GitHub Actions and reusable workflows.
Follow [development guidance](docs/development/README.md) for validation and documentation generation.
Keep public workflows independent of repository bot credentials. Use `$/` references
for actions and workflows from this repository and full commit SHAs for dependencies.
Action and workflow reference files are generated by CI Dokumentor; change their
metadata and regenerate them with `make docs`.
