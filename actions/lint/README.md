## Overview

Run project-locked Ruff, Black and mypy. All three checks run even if one fails. Ruff SARIF reports are retained after failures. Run setup-python first.

See the [usage guide](../../docs/usage/README.md).

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: hoverkraft-tech/ci-github-python/actions/lint@21adde808aee6de52659796134d3d6c58759aac0 # main
  with:
    # uv project directory.
    # Default: `.`
    working-directory: .

    # Trusted Bash command replacing the default checks. Generate SARIF or Checkstyle reports for annotations.
    command: ""

    # Outer calling job ID for consolidated ci-reports. Defaults to the current job ID. No individual PR comments are posted.
    report-group: ""
```
