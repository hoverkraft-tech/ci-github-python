## Overview

Build a wheel and source distribution without local uv sources, then install each in its own clean environment outside the checkout. Does not publish. Run setup-python first.

See the [usage guide](../../../docs/usage/README.md).

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: hoverkraft-tech/ci-github-python/actions/package/test@f7c68ebb3ea6d60da7b6c741b2fc8fb67866cd4a # main
  with:
    # uv package directory with a build-system.
    # Default: `.`
    working-directory: .

    # Optional trusted Bash smoke tests run separately against the installed wheel and sdist. The consumer venv is on PATH; PACKAGE_NAME and PACKAGE_VERSION identify the distribution. Source checkout is not the working directory.
    commands: ""
```
