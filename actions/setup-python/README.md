## Overview

Install Python and uv, cache downloads, and synchronize a committed uv.lock. Uses .python-version or requires-python unless an explicit version is supplied. Build backends can execute code during installation.

See the [usage guide](../../docs/usage/README.md).

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: hoverkraft-tech/ci-github-python/actions/setup-python@f7c68ebb3ea6d60da7b6c741b2fc8fb67866cd4a # main
  with:
    # uv project directory inside the checkout.
    # Default: `.`
    working-directory: .

    # Explicit Python version. Empty uses the project's .python-version or requires-python.
    python-version: ""

    # Pinned uv release.
    # Default: `0.13.9`
    uv-version: 0.13.9

    # Synchronize locked dependencies and the project. Disable for tooling-only jobs.
    # Default: `true`
    install-dependencies: "true"
```
